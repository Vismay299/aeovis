# ADR — DataForSEO as an answer-engine provider

> <!-- doc-status -->
> **Status: LIVE.** Decision record for F02 phase 1. Unblocks F02 phases 2–5.

**Date:** 2026-11-10 · **Run id:** offcult-2026-11-05-v2 · **Owner:** Vismay · **Decision:** partial-go
**Approved engines:** aio, chatgpt, gemini

## Context

F02 §1 asked whether DataForSEO can supply the answers Perceev scores, in place of or alongside the current providers. The owner-run bake-off captured the Offcult question panel through DataForSEO's LLM Scraper (ChatGPT, Gemini) and Google SERP AI Overview endpoints, from an India location, and scored them with the existing pipeline (`probeTextEngine`). No answer was generated by a model API in this run.

## Method

- **Panel:** Offcult, 32 questions (unbranded plus 2 branded diagnostics), market India. Panel file kept private; SHA-256 prefix `3191fe5ebe1dfb2a`. No prompt text appears in this record.
- **Arms:** `dfs_queued` and `dfs_live` (ChatGPT, Gemini, AI Overviews). `dfs_model` (Perplexity via LLM Responses) and `current` (existing providers) were **not** run.
- **Ceilings:** `--max-spend-usd 0.80`, `--max-requests 400`, loopback database `aeovis_live_qa` (Postgres 16).
- **Runs:**
  - `offcult-2026-11-04-v1`, USD 0.47 — discarded: the competitor roster was passed in the wrong format.
  - `offcult-2026-11-05-v2`, USD 0.34 — the run of record. It stopped partway through live Gemini when a request outlived its 120-second lease. Results were recovered from the trial database. Both defects were fixed in #40 (`ecce3a0`). Code at run time: `main` before #40.
- **Balance:** USD 1.00 credit before both runs; about USD 0.19 remaining after.
- Because run 2 stopped early, the script did not write `summary.md`; the figures below were recovered from the trial database.

- India acceptance: 100 % on every arm that ran.
- Queued results arrived within 2–4 minutes.

- Some queued answers came back empty (no text, no citations). The pipeline types these as errors, not as non-mentions.

## Consequences

- F02 phases 2–5 may proceed. Phase 3 sets `DATAFORSEO_APPROVED_ENGINES=aio,chatgpt,gemini`, matching this record (F02-AC-12).
- F13–F17 (SEO features) are unblocked once F02 phase 2 merges.
- The current providers stay as the fallback until phase 3 routes scans to DataForSEO.
- The per-answer reservation (`SCAN_PROBE_RESERVATION_USD`) should be lowered to match DataForSEO's price once phase 3 merges.

## What is NOT verified

- Perplexity through DataForSEO.
- A same-run comparison with the current providers or Bright Data (rule (g)).
- Live AI Overviews; live Gemini reliability.
- DataForSEO LLM Responses (model API) for any engine, which F11 needs.
- Which model answered each scraper request: LLM Scraper responses carry no model name.
- Answers come from logged-out sessions; logged-in users may see personalised answers.
